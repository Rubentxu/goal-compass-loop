# ADR-003: Matt como capacidades enlazadas

**Estado:** ACEPTADA (diseño de referencia) · 2026-10-19

## Contexto
Matt ya aporta investigación, TDD, diseño y código review; hay skills user-invoked y model-invoked.

## Decisión
Descubrir la instalación real, leer su contrato, delegar solo cuando permitido, fallback local cuando falte; no fork ni vendor.

## Alternativas descartadas
Duplicar el catálogo, descargar en runtime, invocar automáticamente `user-invoked`.

## Consecuencias
Las skills opcionales no condicionan el uso básico; la fidelidad exacta requiere instalación externa.
