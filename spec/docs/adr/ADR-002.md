# ADR-002: Grafo de prompts hipermedia

**Estado:** ACEPTADA (diseño de referencia) · 2026-10-19

## Contexto
Cargar un árbol entero aumenta tokens y empuja al agente por fases rígidas.

## Decisión
Nodos Markdown con enlaces tipados `rel`, condiciones y evidencia requerida; lee el nodo actual. El modelo aplica guardas, no un router imperativo.

## Alternativas descartadas
YAML DSL, embeddings, servidor HTTP, motor HATEOAS, JSON duplicado.

## Consecuencias
No es HATEOAS dinámico real; evaluar calidad en tareas concretas. Si el modelo falla repetidamente, añadir evaluador puro muy pequeño.
