# ADR-001: Skill-first y Goal nativo

**Estado:** ACEPTADA (diseño de referencia) · 2026-10-19

## Contexto
El usuario quiere el comportamiento iterativo de `/goal` sin otro agente. MCode ya expone goal persistente.

## Decisión
Una única Skill router independiente `goal-compass`; sin sesiones propias, hooks, MCP ni daemon. Invocación de Goal por usuario como capacidad separada.

## Alternativas descartadas
Reimplementar `/goal`; `Stop` hook como motor de continuation; orquestador JS con estado.

## Consecuencias
MVP sin auto-goal desde la Skill, test sencillo. Reconsiderar integración solo con API pública estable.
